http

The http package is an HTTP client. Requests run asynchronously on background tasks; the get and await_* functions wait for the result and wrap it in an HttpResponse. The package also parses raw HTTP requests and builds raw responses for servers written on top of socket. For a full web server, see httpserver.

Making requests

http::set_timeout(ms) sets the timeout for later requests, and await_download(url, path) saves a response to a file.

Responses

Section titled “Responses”

An HttpResponse has these fields and methods:

MemberDescription
statusThe status code.
oktrue for a 2xx status.
headersThe response headers.
bodyThe response body.
urlThe final URL after redirects.
text()The body as a string.
json()The body parsed as JSON.
pretty()The JSON body, indented.
save(path)Writes the body to a file.

http::parse_hex

Section titled “http::parse_hex”

Parses a hexadecimal string to an integer.

ParameterTypeDefaultDescription
sstringA lowercase hexadecimal string (e.g., "1f").

Returns integer — The integer value.

Throws string — If an invalid hex character is encountered.

http::url_decode

Section titled “http::url_decode”

Decodes a percent-encoded URL string.

ParameterTypeDefaultDescription
sstringThe URL-encoded string to decode.
decode_plusbooleantrueIf true, decodes + as a space (default true).

Returns string — The decoded string.

http::read_crlf_line

Section titled “http::read_crlf_line”

Reads a CRLF-terminated line from a byte iterator.

ParameterTypeDefaultDescription
iterobjectA ListIterator over the raw bytes.

Returns string — The line contents, without the trailing CRLF.

Throws string — If no CRLF terminator is found before the iterator is exhausted.

http::dechunk

Section titled “http::dechunk”

Decodes a chunked transfer-encoded byte sequence.

ParameterTypeDefaultDescription
databytesThe raw chunked-encoded bytes.

Returns bytes — The decoded body bytes.

Throws string — If a chunk size or terminator is malformed or the data is incomplete.

http::parse

Section titled “http::parse”

Parses raw socket bytes into a request hashmap.

ParameterTypeDefaultDescription
rawbytesThe raw bytes received from a socket.

Returns hashmap|none — A hashmap with method, path, query, version, headers, body, form, and raw keys, or null if the request is malformed or incomplete.

http::response_bytes

Section titled “http::response_bytes”

Builds a raw HTTP/1.1 response as bytes.

ParameterTypeDefaultDescription
statusintegerThe HTTP status code (e.g., 200, 404).
bodyany""The response body — a string or bytes (default "").
headershashmap{}Additional headers to include or override defaults (default {}).

Returns bytes — The fully-formed HTTP response bytes, including headers and body.
