error

The error package builds the structured errors that Kiwi’s try/catch understands, inspects caught errors, and provides guard helpers that throw when a check fails. Error Handling explains how errors are thrown and caught; this page is the package reference.

A structured error is a hashmap with an error key (the type name) and a message key:

type_of, message_of and is_type also accept the plain strings that a two-variable catch type, message gives you.

Constructors

Section titled “Constructors”

error::new(type, message) makes an error with any type name. The named constructors take an optional message:

ConstructorDefault message
ArgumentErrorInvalid argument.
AssertionErrorAssertion failed.
IndexErrorIndex out of bounds.
IOErrorI/O error.
InvalidOperationInvalid operation.
InvalidRangeInvalid range.
KeyErrorKey not found.
NetworkErrorNetwork error.
NotFoundErrorNot found.
NotImplementedErrorNot implemented.
OverflowErrorOverflow.
ParseErrorParse error.
PermissionErrorPermission denied.
TimeoutErrorOperation timed out.
TypeErrorType error.
ValueErrorInvalid value.

Guards

Section titled “Guards”
FunctionThrows when
assert(condition, message)condition is false (AssertionError)
expect_type(value, type, name)value is not of type type (TypeError)
expect_not_null(value, name)value is null (ValueError)

Functions

Section titled “Functions”

error::new

Section titled “error::new”

Creates a structured error hashmap.

ParameterTypeDefaultDescription
error_typestring"Error"The error type name (default "Error").
error_messagestring"An error occurred."The error message (default "An error occurred.").

Returns hashmap — A hashmap with error and message keys.

error::type_of

Section titled “error::type_of”

Returns the type string of a caught error.

ParameterTypeDefaultDescription
erranyA caught error hashmap (from single-param catch e) or a plain string.

Returns string — The error key if err is a structured hashmap, otherwise err as a string.

error::message_of

Section titled “error::message_of”

Returns the message of a caught error.

ParameterTypeDefaultDescription
erranyA caught error hashmap (from single-param catch e) or a plain string.

Returns string — The message key if err is a structured hashmap, otherwise err as a string.

error::is_type

Section titled “error::is_type”

Returns true if the caught error matches a specific type name.

ParameterTypeDefaultDescription
erranyA caught error hashmap (from single-param catch e) or a plain string.
error_typestringThe type name to match against.

Returns boolean — true if the error type matches.

error::assert

Section titled “error::assert”

Throws an AssertionError if condition is false.

ParameterTypeDefaultDescription
conditionbooleanThe condition to check.
msgstring"Assertion failed."The error message (default "Assertion failed.").

Throws AssertionError — If condition is false.

error::expect_type

Section titled “error::expect_type”

Throws a TypeError if val is not of the expected type.

ParameterTypeDefaultDescription
valanyThe value to check.
expected_typestringThe expected type name (e.g., "integer", "string").
namestring"value"An optional label for the value, used in the error message.

Throws TypeError — If val.type() does not match expected_type.

error::expect_not_null

Section titled “error::expect_not_null”

Throws a ValueError if val is null.

ParameterTypeDefaultDescription
valanyThe value to check.
namestring"value"An optional label for the value, used in the error message.

Throws ValueError — If val == null.
