math

The math package has the usual mathematical functions.

The functions accept integers and floats alike. Those that compute a float, such as sqrt and floor, return a float even for an integer argument.

GroupFunctions
Powers and rootssqrt, cbrt, pow, exp, expm1, hypot
Logarithmslog, log2, log10, log1p
Trigonometrysin, cos, tan, asin, acos, atan, atan2, sinh, cosh, tanh
Roundingfloor, ceil, round, trunc
Comparisonabs, fmax, fmin, fdim, copysign, nextafter
Divisionfmod, remainder, divmod, ediv, emod
Classificationisfinite, isinf, isnan, isnormal
Special functionserf, erfc, lgamma, tgamma
Randomrandom, random_set
Primeslistprimes, nthprime
Precisionepsilon, eps

Random numbers

Section titled “Random numbers”

random(low, high) returns a random number between the bounds: an integer for integer bounds, a float for float bounds. random_set(low, high, count) returns a list of random integers.

For realistic fake data, see faker.

Euclidean division

Section titled “Euclidean division”

ediv and emod perform Euclidean division, whose remainder is never negative, unlike %. divmod returns both as a list.

They satisfy dividend == divisor * ediv(dividend, divisor) + emod(dividend, divisor).

For statistics such as mean, median and standard deviation, see stat.
