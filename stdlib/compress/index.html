compress

The compress package compresses and decompresses data in memory. Every function accepts a string or bytes and returns bytes; call .to_string() on the result to get text back.

FormatCompressDecompress
DEFLATEdeflateinflate
GZipgzipgunzip
Brotlibrotliunbrotli
Zstandardzstdunzstd
ZIP archivezip_createzip_extract

Section titled “compress::deflate”

ParameterTypeDefaultDescription

compress::zip_create

Section titled “compress::zip_create”

Creates a ZIP archive from a list of entries.

ParameterTypeDefaultDescription
entrieslistA list of file entries to include in the archive.
levelinteger1Compression level (default 1).

Returns bytes — The ZIP archive as bytes.

compress::zip_extract

Section titled “compress::zip_extract”

Extracts entries from a ZIP archive.

ParameterTypeDefaultDescription
databytesThe ZIP archive as bytes.

Returns list — A list of extracted entries.
