bench

The bench package measures how long code takes. A benchmark is a lambda; bench runs it a number of times after a short warmup and reports the mean, median, minimum, maximum and standard deviation.

Benchmarking a suite

Section titled “Benchmarking a suite”

Benchmarking one thing

Section titled “Benchmarking one thing”

run benchmarks a single lambda and returns its statistics:

Every result is a hashmap with these keys. Times are in milliseconds.

KeyMeaning
nameThe benchmark name
iterationsThe number of timed runs
totalTotal time across all runs
mean, medianAverage and median time per run
min, maxFastest and slowest run
stddevPopulation standard deviation

Timing calls

Section titled “Timing calls”

@bench::timed prints the elapsed time of every call to a function, and @bench::profile(name, iterations, warmup) benchmarks a function once, as soon as it is defined.

Functions

Section titled “Functions”

bench::initialize

Section titled “bench::initialize”

Initializes the global benchmark registry if not already set up.

bench::register

Section titled “bench::register”

Registers a named benchmark lambda for later execution by run_all().

ParameterTypeDefaultDescription
namestringThe display name of the benchmark.
blambdaA no-argument lambda containing the code to benchmark.

bench::stats

Section titled “bench::stats”

Computes descriptive statistics from a list of timing values.

ParameterTypeDefaultDescription
timingslistA list of float timing values (in ms).

Returns hashmap — A hashmap with keys: total, mean, median, min, max, stddev.

bench::fmt

Section titled “bench::fmt”

Formats a float timing value as a string with 3 decimal places and "ms" suffix.

ParameterTypeDefaultDescription
valfloatThe timing value in milliseconds.

Returns string — The formatted string (e.g., "1.234ms").

bench::run

Section titled “bench::run”

Runs a single named benchmark, printing a one-line result.

ParameterTypeDefaultDescription
namestringThe display name of the benchmark.
blambdaA no-argument lambda containing the code to benchmark.
iterationsinteger100Number of timed iterations to run (default 100).
warmupinteger5Number of warmup iterations before timing (default 5).

Returns hashmap — A result hashmap with keys: name, iterations, total, mean, median, min, max, stddev.

bench::run_all

Section titled “bench::run_all”

Runs all registered benchmarks and prints a summary table.

ParameterTypeDefaultDescription
iterationsinteger100Number of timed iterations per benchmark (default 100).
warmupinteger5Number of warmup iterations per benchmark (default 5).

Returns list — A list of result hashmaps for all registered benchmarks.

bench::mark

Section titled “bench::mark”

Decorator — registers a function in the global benchmark registry for bench::run_all(). The decorated function remains callable normally.

ParameterTypeDefaultDescription
flambdaThe function to register (injected by the decorator system).
namestring"benchmark"The display name of the benchmark (required).

Returns lambda — The original function, unmodified.

bench::profile

Section titled “bench::profile”

Decorator — immediately runs a benchmark of the decorated function at definition time. The decorated function remains callable normally.

ParameterTypeDefaultDescription
flambdaThe function to benchmark (injected by the decorator system).
namestring"benchmark"The display name (default: "benchmark").
iterationsinteger100Number of timed iterations (default: 100).
warmupinteger5Number of warmup iterations (default: 5).

Returns lambda — The original function, unmodified.

bench::timed

Section titled “bench::timed”

Decorator — wraps a function so that every call prints its elapsed time.

ParameterTypeDefaultDescription
flambdaThe function to wrap (injected by the decorator system).

Returns lambda — A wrapper that times each call and prints the result.

bench::print_summary

Section titled “bench::print_summary”

Prints a formatted summary table of benchmark results.

ParameterTypeDefaultDescription
resultslistA list of result hashmaps from run() or run_all().
