Kiwi

A scripting language with a small, readable syntax and a standard library that covers files, data formats, HTTP, databases and concurrency out of the box.
Get startedTake the tourView on GitHub

Readable by default

Blocks close with end, strings interpolate with ${...}, and guards like return x when done keep control flow flat.

Batteries included

CSV, JSON, YAML, XML, SQLite, HTTP client and server, sockets, compression and more, with nothing to install.

Data friendly

Lists and hashmaps with map, filter and reduce, plus a table package for joins and grouping.

Concurrency built in

Spawn tasks, pass values over channels, and guard shared state with mutexes.
