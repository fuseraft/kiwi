# Kiwi Documentation Map

Quick reference: given a topic, which doc file(s) to consult.

| Topic              | Doc file(s)                                      |
|--------------------|--------------------------------------------------|
| Types overview     | `docs/types.md`                                  |
| Builtins (dot-notation) | `docs/builtins.md`                           |
| Strings            | `docs/strings.md`                                |
| Lists              | `docs/lists.md`                                  |
| Hashmaps           | `docs/hashmaps.md`                               |
| Functions          | `docs/functions.md`                              |
| Lambdas            | `docs/lambdas.md`                                |
| Generators         | `docs/generators.md`                             |
| Structs            | `docs/structs.md`                                |
| Abstract structs   | `docs/abstract_structs.md`                       |
| Error handling     | `docs/error_handling.md`                         |
| Scoping            | `docs/scoping.md`                                |
| Packages           | `docs/packages.md`                               |
| Ranges             | `docs/ranges.md`                                 |
| Type hints         | `docs/type_hints.md`                             |
| Operators          | `docs/operators.md`                              |
| Decorators         | `docs/decorators.md`                             |
| Control flow       | `docs/conditionals.md`, `docs/loops.md`, `docs/control_structures.md` |
| REPL               | `docs/repl.md`                                   |
| Debugger           | `docs/kdb.md`                                    |
| All stdlib         | `docs/lib/*.md` (one file per package)           |
| Examples           | `examples/`                                      |
